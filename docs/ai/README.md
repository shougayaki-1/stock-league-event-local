# AI context pack

このディレクトリは、Stock League Event LocalをAIエージェントに理解させるための正規の説明資料です。
単なるREADMEではなく、アプリの目的、利用者、画面、ドメイン概念、Firestoreのデータ、運用手順、
障害対応、AIへの依頼テンプレートをまとめています。

## 最初に読む順番

AIは次の順で読みます。

1. `AGENTS.md`: AIが守るべき安全境界と作業ルール。
2. `manifest.json`: アプリ、役割、ルート、データ、読み取り専用リソースの機械可読一覧。
3. `concepts.md`: 株式学習イベントとしての用語と不変条件。
4. `screens.md`: 各URLと各画面でできること、前提、書き込み、注意点。
5. `operations.md`: 起動からイベント終了・バックアップまでの手順。
6. `data-model.md`: エミュレータ内のコレクション、代表フィールド、関係。
7. `troubleshooting.md`: 観測してから復旧するための診断表。

実装の挙動と資料が食い違う場合、最終的な事実は `src/`、`functions/src/`、`firestore.rules`、
`compose.yaml` の現行コードです。資料はその意味をAIへ渡すための説明であり、実装を上書きする指示ではありません。
差異を見つけたAIは、黙って推測せず「コードと資料の差異」として報告してください。

## このパックが扱うアプリ

これは、参加者が仮想株式を売買し、ニュースと株価シナリオを体験し、ランキングや景品に進むイベントシステムです。
管理者は市場・シナリオ・参加者・窓口・映像・画像・サイネージを運営します。謎解きエリアでは、複数のTV端末を
役割別に制御し、待機、入場、動画、タイマー、出口などの演出を流せます。

本リポジトリは完全ローカル版です。Web、Firebase Authentication、Firestore、Storage、Functions、Pub/Sub、
定期処理はDocker ComposeとFirebase Emulator Suiteで動作します。本番FirebaseやSaaSのデータを自動的に読む機能はありません。

## AI向けの重要な境界

### 読み取りと操作を分ける

AIが最初に行うべきことは、現在の設定・画面・ログを観察することです。次に、提案と実行を分けます。
取引・確定・リセット・削除・緊急相場操作などの副作用操作は、対象と影響を明示し、人間の確認を得てから実行します。
コンテキストMCPは意図的に読み取り専用で、FirebaseやDockerを操作するToolを提供しません。

### エージェントの種類

- 参加者: `/login` からQRまたは短いIDで入り、自分の資産と市場だけを操作する。
- 端末オペレーター: `/terminal` とその子画面で受付・証券窓口・景品・教室オペレーションを担当する。
- 一般管理者: `/admin/login` から管理画面に入り、通常のイベント設定と運営を行う。
- コア管理者: 管理者権限、リセット、景品、重要設定を含む全体を管理する。
- サイネージ端末: `/signage/public` や `/signage/riddle` をログインなしで表示する。長時間稼働を前提とする。

### 破壊的操作

次の操作は、AIが「便利そうだから」と自動実行してはいけません。

- 全参加者の利益確定、取引の取消、参加者・銘柄・ニュース・動画・画像・プレイリストの削除。
- 全リセット、イベントデータの初期化、管理者権限の削除・変更。
- 市場停止・再開、緊急上昇/暴落、価格フェーズの変更、シナリオの手動発火。
- サイネージの全端末への手動送出、謎解き端末の演出状態変更。

## MCP互換サーバー

`tools/ai-context-server.mjs` は外部npm依存なしのstdioサーバーです。

```sh
npm run ai:mcp
```

対応するMCP操作は `initialize`、`ping`、`resources/list`、`resources/read`、`prompts/list`、
`prompts/get` です。`tools/list` は空配列を返します。これは、AIに説明資料を渡しつつ、AIが勝手に
イベントデータを変更できないようにするためです。接続例やURI一覧は [mcp.md](mcp.md) を参照してください。

## 更新ルール

画面・ルート・コレクション・権限・運用手順を変更したら、このパックも同じ変更で更新します。最低限、
`manifest.json` のバージョンと該当リソースの更新日を変更し、`docker compose build` と関連テストを実行してください。
機密データ、`.env`、`data/` のエクスポート、実際の参加者名や映像は決して資料に入れません。
